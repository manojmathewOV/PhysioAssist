# Clinical source availability

This directory is an engineering index and decision register, NOT an approved clinical protocol library.

The independent reviewer previously located the owner's shoulder/knee protocols in Dropbox and on the synced computer. These originals are not in this public repository. Cloud Claude cannot retrieve them by following a local file path. The index records document families and known ambiguities without pretending to provide the full source.

Before importing a source-dependent numeric rule, obtain the selected approved revision through an authorized delivery channel. The owner may authorize a specific scrubbed document for public publication, or choose access-controlled delivery. Do not make that publication decision on the owner's behalf. Do not claim a source is missing from the owner's library merely because it is intentionally absent here.

See source-index.json for the inventory, APPROVALS.md for decisions, and frozen-shoulder-current-intent.json for the owner's new instruction recorded as a non-activated draft. The draft comes from the direct instruction, not the older private/public handout doses.

A publication/authorization state and a clinical-approval state are different. Neither a filename containing 'public' nor a passing software test proves that a source is approved for redistribution or clinical activation.
